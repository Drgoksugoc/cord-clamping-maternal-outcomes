# Data

This folder contains the publication-ready, de-identified analysis dataset used for the submitted cord-clamping maternal-outcomes manuscript.

| File | Description |
|---|---|
| `PPH_CordClamping.csv` | De-identified CSV analysis dataset with 4,644 delivery episodes and 68 variables. |

A variable-level dictionary with inferred data types, missingness, and example values is available in `../DATA_DICTIONARY.md`. The dataset should be handled as research data and should not be combined with external information for re-identification attempts.
