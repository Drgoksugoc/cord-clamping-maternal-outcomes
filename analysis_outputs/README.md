# Archived analysis outputs

This folder contains the archived outputs from the v16.4 statistical analysis run (`analysis_outputs_cord_clamping_v16_4_complete.zip`). The archive includes all tables, figures, model summaries and quality-control outputs generated by the analysis pipeline.

The canonical reproducibility inputs are the dataset in `data/PPH_CordClamping.csv` (with day-resolution delivery dates) and the statistical script in `analysis/PPH_CordClamping_statistical_script.R` (v16.4). See [`../REPRODUCIBILITY_NOTE.md`](../REPRODUCIBILITY_NOTE.md) for details on reproducing the analysis.
