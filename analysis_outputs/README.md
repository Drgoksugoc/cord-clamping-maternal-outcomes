# Archived analysis outputs

This folder contains an archived set of aggregate analysis outputs, tables and figures generated by the statistical workflow. Patient-level quality-control exports that contained exact delivery-date fields were removed from the public archive during the month-resolution de-identification update.

The retained files are intended to document the analysis results and support comparison with rerun outputs. The canonical reproducibility inputs are the public month-resolution dataset in `data/PPH_CordClamping.csv` and the statistical script in `analysis/PPH_CordClamping_statistical_script.R`.

Because the public dataset excludes exact delivery dates, reruns from the month-resolution dataset may differ slightly from the protected day-resolution v14 reference outputs for calendar-time-adjusted propensity-score methods. See [`../REPRODUCIBILITY_NOTE.md`](../REPRODUCIBILITY_NOTE.md) for the validation summary and interpretation.
