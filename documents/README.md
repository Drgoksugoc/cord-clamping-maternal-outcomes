# Submission documents

This folder contains manuscript-related files that accompany the public reproducibility package. The repository includes documents relevant to article review and reproducibility, while excluding private editorial correspondence.

| File | Purpose |
|---|---|
| `03_Main_Manuscript.docx` | Main manuscript file associated with the study. |
| `06_Supplementary_Materials.docx` | Supplementary methods, tables, and supporting materials. |
| `09_STROBE_Checklist.docx` | STROBE reporting checklist for the observational study design. |

These documents are included for transparency and may not exactly match the final accepted journal version if the article is revised during peer review.
